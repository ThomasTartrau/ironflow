# Security policy

## Supported versions

Only the latest release of the `ironflow-*` crates on crates.io receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately with a confidential GitLab issue:
https://gitlab.com/ThomasTartrau/ironflow/-/issues/new?issue[confidential]=true

Security maintainer: Thomas Tartrau ([@ThomasTartrau](https://gitlab.com/ThomasTartrau))

I aim to acknowledge reports within 72 hours and to publish a fix and a security advisory once the issue is resolved. Reporters are credited in the advisory unless they ask otherwise.
